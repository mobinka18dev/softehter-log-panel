## ۱. معرفی نرم‌افزار و قابلیت‌ها

نرم‌افزار **SoftEther VPN Log Panel** یک سامانه تحت وب، امن و مدرن جهت تحلیل دقیق و گزارش‌گیری از تاریخچه اتصال کاربران سرور **SoftEther VPN** است.

### قابلیت‌های کلیدی:
- **تحلیل بدون دستکاری:** اتصال کاربران، مدت زمان اتصال، آی‌پی پابلیک، هاب مجازی متصل و حجم تبادل دیتا را مستقیماً از لاگ‌های متنی استخراج می‌کند.
- **تطبیق هوشمند نشست‌ها (Session Correlation):** رخدادهای ورود و خروج هر کاربر را بدون ادغام اشتباه نشست‌های همزمان یا ساختگی بودن داده‌ها متناظر می‌کند.
- **تشخیص قطعی و ریستارت سرور:** در صورت ریستارت سرور VPN یا قطع ناگهانی اینترنت کلاینت، نشست‌ها با وضعیت `ناقص (Incomplete)` و ذکر علت دقیق علامت‌گذاری می‌شوند.
- **پشتیبانی کامل از تقویم شمسی (جلالی) و میلادی:** فیلترهای روز، دیروز، ۷ روز گذشته، ۳۰ روز گذشته، این ماه، و بازه زمانی دلخواه با احتساب ثانیه آخر روز (۲۳:۵۹:۵۹).
- **گزارشات چند برگه‌ای اکسل (Excel):** شامل شیت خلاصه مدیریتی و شیت جزئیات نشست‌ها به زبان فارسی و انگلیسی.
- **مدیریت کاربران پنل و سطوح دسترسی (RBAC):** نقش‌های مدیر ارشد (Superadmin)، مدیر (Admin) و مشاهده‌گر (Viewer) با هش رمزنگاری مدرن **Argon2id**.
- **ایمن در برابر حملات:** محدودسازی نرخ تلاش‌های ورود (Rate Limiting)، محافظت CSRF/XSS و ثبت گزارشات ممیزی (Audit Logs).
- **کاملاً آفلاین و ایزوله:** عدم نیاز به اینترنت در زمان کارکرد عادی؛ تمامی فایل‌های استاتیک در داخل پنل قرار دارند.
- **عدم وابستگی به روت:** سرویس تحت کاربر سیستمی غیر روت `softether-panel` اجرا می‌شود و هیچ تداخلی با عملیات شبکه سرور VPN ندارد.

> [!IMPORTANT]
> **نکته بسیار مهم:** کاربران پنل مدیریت و کاربران VPN دو موضوع کاملاً مستقل هستند. ایجاد یا حذف کاربر در این پنل به هیچ وجه حسابی را در سرور SoftEther VPN ایجاد، ویرایش یا حذف نمی‌کند.

## ۲. معماری سیستم و نحوه عملکرد

این سیستم بر پایه فناوری‌های سبک و پایدار پیاده‌سازی شده است:
- **بک‌اند:** زبان Python 3 با فریمورک پرسرعت **FastAPI**.
- **پایگاه داده:** پایگاه داده فایل‌محور SQLite در حالت **WAL (Write-Ahead Logging)** با ایندکس‌های بهینه‌سازی‌شده برای جستجوی میلی‌ثانیه‌ای در میلیون‌ها رکورد.
- **موتور استریم لاگ (Log Synchronizer):** فایل‌های لاگ بزرگ (حتی بیش از ۱ گیگابایت) را به صورت خط به خط و با رهگیری آفست بایتی (Byte Offset) می‌خواند؛ در نتیجه فایل در حافظه رم بارگذاری نمی‌شود و مصرف منابع بسیار پایین می‌ماند.
- **فرانت‌اند:** رابط کاربری مدرن، واکنش‌گرا و تک‌صفحه‌ای (SPA) با پشتیبانی راست‌به‌چپ (RTL) و تم‌های Dark/Light.

---

## ۳. لاگ‌های مورد نیاز SoftEther VPN

این پنل دو دسته لاگ اصلی SoftEther را پردازش می‌کند:
1. **Server Log (`server_log/`):** شامل لاگ‌های استارت/استاپ سرویس و اتصال اولیه سوکت‌های کلاینت. نام فایل‌ها معمولاً `vpn_YYYYMMDD.log` است.
2. **Security Log (`security_log/<HUB_NAME>/`):** لاگ‌های احراز هویت موفق، ایجاد نشست (`SID-...`)، خروج و آمار تبادل دیتا برای هر هاب مجازی. نام فایل‌ها `sec_YYYYMMDD.log` است.

---

## ۴. یافتن مسیر واقعی لاگ‌ها در سرور

در سرور لینوکس اوبونتو، پوشه اصلی SoftEther بسته به نحوه نصب معمولاً در یکی از مسیرهای زیر قرار دارد:
- `/usr/local/vpnserver/` (مسیر پیش‌فرض رایج)
- `/var/log/vpnserver/`

برای اطمینان از مسیر دقیق در سرور لینوکس دستور زیر را اجرا کنید:
```bash
# پیدا کردن مسیر اجرایی یا لاگ‌های سرور SoftEther
sudo find / -name "server_log" -type d 2>/dev/null
```
اگر خروجی `/usr/local/vpnserver/server_log` بود، مسیر ریشه لاگ‌های شما `/usr/local/vpnserver` است.

## ۵. پیکربندی دسترسی فقط-خواندنی (Read-Only ACL)

برای اینکه امنیت سیستم حفظ شود و هیچ دستکاری تصادفی در لاگ‌های اصلی اتفاق نیفتد، به جای تغییر مالکیت فایل‌ها، از **POSIX ACL** برای اعطای دسترسی فقط-خواندنی به کاربر `softether-panel` استفاده می‌شود:

```bash
# نصب پکیج acl در اوبونتو (در صورت عدم وجود)
sudo apt-get install -y acl

# اعطای دسترسی خواندن و پیمایش به کاربر پنل روی لاگ‌ها
sudo setfacl -R -m u:softether-panel:rX /usr/local/vpnserver/server_log
sudo setfacl -R -m u:softether-panel:rX /usr/local/vpnserver/security_log

# تنظیم دسترسی پیش‌فرض برای لاگ‌هایی که در آینده توسط SoftEther ایجاد می‌شوند
sudo setfacl -R -d -m u:softether-panel:rX /usr/local/vpnserver/server_log
sudo setfacl -R -d -m u:softether-panel:rX /usr/local/vpnserver/security_log
```
> [!NOTE]
> با دستورات فوق، سرویس SoftEther بدون کمترین تغییری به فعالیت خود ادامه می‌دهد و لاگ پنل فقط قادر به خواندن لاگ‌ها خواهد بود.

## ۶. مراحل نصب روی سرور اوبونتو

هدف سرور اوبونتو ۲۲.۰۴ / ۲۴.۰۴ (با آی‌پی `192.168.5.6`):

1. اجرای دستور یک‌خطی نصب مستقیم در ترمینال سرور:
   ```bash
   git clone https://github.com/mobinka18dev/softehter-log-panel.git /opt/softether-log-panel
   cd /opt/softether-log-panel
   sudo bash deploy/install.sh
   ```
   اسکریپت به صورت کاملاً خودکار و بدون نیاز به مداخله دستی:
   - نسخه سیستم‌عامل اوبونتو را بررسی می‌کند.
   - کاربر سیستمی ایزوله `softether-panel` را ایجاد می‌کند.
   - وابستگی‌های سیستمی و محیط مجازی پایتون (`.venv`) را پیکربندی می‌کند.
   - کلید امنیتی ۶۴ بایتی تصادفی ایجاد می‌نماید.
   - مجوزهای امنیتی فقط-خواندنی (POSIX ACL) را با ایزولاسیون کامل دایرکتوری `/root` و فایل `vpn_server.config` تنظیم می‌کند.
   - دیتابیس SQLite WAL را راه‌اندازی می‌کند.
   - سرویس `systemd` با نام `softether-panel.service` را فعال و روشن می‌کند.

### تست‌های بررسی صحت و امنیت پس از نصب:
```bash
# ۱. اطمینان از مسدود بودن دسترسی به فایل‌های روت و کانفیگ سرور SoftEther (باید خروجی Permission denied بدهد):
sudo -u softether-panel ls -la /root
sudo -u softether-panel cat /root/vpnserver/vpn_server.config

# ۲. اطمینان از دسترسی فقط-خواندنی به لاگ‌های سرور (باید لیست لاگ‌ها را نمایش دهد):
sudo -u softether-panel ls -la /root/vpnserver/server_log

# ۳. بررسی وضعیت سلامت و آماده‌به‌کار بودن وب‌سرویس:
curl -s http://127.0.0.1:8080/api/health
```

## ۷. پیکربندی متغیرهای محیطی (.env)

فایل تنظیمات در مسیر `/opt/softether-log-panel/.env` قرار دارد:
```ini
APP_NAME="SoftEther VPN Log Panel"
APP_ENV=production
DEBUG=false
HOST=0.0.0.0
PORT=8080
SECRET_KEY=یک_رشته_تصادفی_بسیار_امن
ACCESS_TOKEN_EXPIRE_MINUTES=480
DATABASE_PATH=/opt/softether-log-panel/data/panel.db
SOFTETHER_LOG_DIR=/root/vpnserver
SYNC_INTERVAL_SECONDS=15
AUTO_SYNC_ENABLED=true
MAX_LOG_LINE_BATCH=5000
```
- برای تغییر پورت، مقدار `PORT` را ویرایش کرده و سرویس را با `sudo systemctl restart softether-panel` ریستارت کنید.

## ۸. نحوه دسترسی به پنل تحت وب

پس از اجرای موفق اسکریپت نصب، مرورگر خود را در یکی از کامپیوترهای متصل به شبکه محلی باز کرده و آدرس زیر را وارد کنید:

```text
http://192.168.5.6:8080
```

> [!TIP]
> جهت امنیت، پورت ۸۰۸۰ به صورت پیش‌فرض فقط برای دسترسی‌های درون شبکه محلی (LAN) مناسب است و نیازی به باز کردن پورت به سمت اینترنت عمومی نیست.

## ۹. ایجاد اولین مدیر سیستم (Superadmin)

دو روش برای ایجاد اولین مدیر سیستم وجود دارد:

### روش ۱: از طریق محیط وب (Setup Wizard)
در اولین مراجعه به پنل، چنانچه هیچ کاربری در سیستم نباشد، پنجره راه‌اندازی اولیه ظاهر می‌شود که می‌توانید نام کاربری و رمز عبور مدیر ارشد را تعیین نمایید. پس از ایجاد اولین کاربر، این صفحه برای همیشه قفل می‌شود.

### روش ۲: از طریق خط فرمان سرور (CLI)
دستور زیر را در ترمینال سرور اوبونتو اجرا کنید:
```bash
sudo -u softether-panel /opt/softether-log-panel/.venv/bin/python /opt/softether-log-panel/manage.py create-admin
```
اطلاعات خواسته شده (نام کاربری، رمز عبور حداقل ۸ کاراکتر و سطح دسترسی) را وارد نمایید.

## ۱۰. واردسازی لاگ‌های قدیمی و همگام‌سازی

پنل به صورت خودکار هر ۵ دقیقه (بر اساس `SYNC_INTERVAL_SECONDS`) فایل‌های جدید یا سطرهای اضافه شده را می‌خواند.

جهت اجرای فوری همگام‌سازی دستی لاگ‌های قدیمی:
- **از طریق وب:** رفتن به تب «همگام‌سازی لاگ» و زدن دکمه «شروع همگام‌سازی دستی».
- **از طریق ترمینال:**
  ```bash
  sudo -u softether-panel /opt/softether-log-panel/.venv/bin/python /opt/softether-log-panel/manage.py sync-logs
  ```

## ۱۱. تولید و فیلتر گزارشات کاربران

در بخش **«گزارشات کاربران»**:
1. نام کاربری مورد نظر را تایپ کنید (قابلیت Autocomplete برای تکمیل خودکار فعال است).
2. هاب مجازی را انتخاب یا روی «همه هاب‌ها» قرار دهید.
3. بازه تاریخی دلخواه را به **شمسی** یا **میلادی** وارد کنید.
4. دکمه «جستجو» را بزنید.
5. جدول نتایج شامل ستون‌های:
   - نام کاربری
   - وضعیت (تکمیل‌شده، فعال، ناقص)
   - زمان دقیق ورود (شمسی و میلادی)
   - زمان دقیق خروج (شمسی و میلادی)
   - مدت اتصال محاسبه‌شده
   - آی‌پی پابلیک کلاینت
   - هاب مجازی و شناسه نشست (Session ID)
6. کارت خلاصه آماری مجموع مدت تاییدشده، میانگین نشست‌ها، طولانی‌ترین اتصال و نشست‌های ناقص را بلافاصله نمایش می‌دهد.

## ۱۲. خروجی اکسل (Excel) و CSV

- با زدن دکمه **«خروجی اکسل (Excel)»**، فایلی با پسوند `.xlsx` دانلود می‌شود که شامل:
  - **برگ اول (خلاصه گزارش):** فیلترهای انتخابی، تاریخ استخراج و آمار تجمعی.
  - **برگ دوم (جزئیات نشست‌ها):** جدول کامل نشست‌های فیلتر شده با ستون‌های تاریخ شمسی و میلادی و استایل رسمی.
- با زدن دکمه **«خروجی CSV»**، فایلی با استاندارد UTF-8 BOM دانلود می‌شود که هنگام باز کردن در اکسل ویندوز، حروف فارسی دچار به‌هم‌ریختگی نمی‌شوند.

## ۱۳. بروزرسانی نرم‌افزار

برای بروزرسانی سریع پنل:
```bash
cd /opt/softether-log-panel
sudo git pull origin main
sudo systemctl restart softether-panel
```

یا برای اجرای اسکریپت بروزرسانی خودکار همراه با تهیه نسخه پشتیبان پیش از آپدیت:
```bash
sudo bash /opt/softether-log-panel/deploy/update.sh
```
این اسکریپت پیش از اعمال هرگونه تغییر، یک بکاپ خودکار از دیتابیس گرفته و سپس آپدیت‌ها را اعمال و سرویس را مجدداً راه‌اندازی می‌کند.

## ۱۴. پشتیبان‌گیری و بازیابی اطلاعات

### پشتیبان‌گیری:
```bash
sudo bash /opt/softether-log-panel/deploy/backup.sh
```
فایل پشتیبان فشرده شامل دیتابیس نشست‌ها و تنظیمات `.env` در مسیر `/opt/softether-log-panel/backups/backup_YYYYMMDD_HHMMSS.tar.gz` ذخیره می‌شود.

### بازیابی:
```bash
sudo bash /opt/softether-log-panel/deploy/restore.sh /opt/softether-log-panel/backups/نام_فایل_بکاپ.tar.gz
```

## ۱۵. حذف کامل پنل بدون تاثیر بر SoftEther

اگر روزی تصمیم به حذف پنل گرفتید:
```bash
sudo bash /opt/softether-log-panel/deploy/uninstall.sh
```
این دستور:
- سرویس `softether-panel.service` را متوقف و حذف می‌کند.
- کاربر `softether-panel` و پوشه نصب را پاکسازی می‌کند.
- **به هیچ عنوان به سرویس SoftEther VPN، فایل‌های لاگ اصلی و تنظیمات شبکه دست نمی‌زند.**

## ۱۶. عیب‌یابی خطاهای رایج

### الف) پیام "No security_log files found" یا لاگ‌ها خالی است:
- در نرم‌افزار مدیریت SoftEther (SoftEther VPN Server Manager):
  - به بخش **Hub Administration** مربوط به هاب مورد نظر بروید.
  - روی **Log Setting** کلیک کنید.
  - گزینه **Save Security Log** را تیک بزنید و سطح آن را روی مناسب قرار دهید.

### ب) سرویس استارت نمی‌شود:
برای مشاهده خطاهای سیستم‌عامل دستور زیر را بزنید:
```bash
sudo journalctl -u softether-panel -n 50 --no-pager
```

### ج) فراموشی رمز عبور ادمین:
از طریق خط فرمان بدون نیاز به وب می‌توانید رمز هر کاربری را ریست کنید:
```bash
sudo -u softether-panel /opt/softether-log-panel/.venv/bin/python /opt/softether-log-panel/manage.py reset-password
```
